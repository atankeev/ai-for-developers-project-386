# Календарь звонков

Сервис бронирования времени: гость выбирает тип встречи и записывается на свободное время.

## Термины

**Запись**:
Договорённость о встрече гостя с владельцем на определённый интервал времени, возникающая после успешного подтверждения сервером. Выбор времени гостем сам по себе записью не является.
_Избегать_: «бронь» как отдельная сущность или предварительный резерв времени.

**Отмена записи**:
Прекращение договорённости о встрече по решению владельца до её начала, освобождающее занятый интервал. Отменённая запись сохраняется как факт отмены.

**Подтверждение записи**:
Доступное гостю по секретной ссылке представление условий и текущего статуса его записи. Оно не содержит имени, email и комментария гостя.

**Владелец**:
Единственный заранее заданный пользователь, который управляет типами встреч, расписанием и записями гостей.

**Гость**:
Человек, который выбирает тип встречи и записывается на неё без регистрации.

**Тип встречи**:
Предложение встречи с названием, описанием и длительностью, созданное владельцем.

**Каталог типов встреч**:
Доступный гостю список типов встреч, из которого он выбирает встречу перед выбором даты и времени. В интерфейсе называется «Записаться».
_Избегать_: «страница записи» для обозначения каталога — это название не отличает каталог от последующих шагов бронирования.

**Расписание владельца**:
Повторяющиеся недельные часы доступности, общие для всех типов встреч. Расписание задаётся по московскому времени.

**Исключение из расписания**:
Изменение доступности на конкретную дату: полностью закрытый день или рабочие часы, заменяющие недельное расписание для этого дня.

**Рабочий интервал**:
Непрерывный период доступности владельца в пределах одного календарного дня по московскому времени; в дне может быть несколько непересекающихся рабочих интервалов. Встреча целиком помещается в один рабочий интервал; доступность через полночь задаётся отдельными интервалами для двух дней.
