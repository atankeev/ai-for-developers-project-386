# Domain docs

Используется единый контекст для фронтенда, бекенда и API-контракта.

Перед изучением кода:

- Прочитайте GLOSSARY.md в корне.
- Прочитайте решения из docs/adr/, относящиеся к текущей задаче.

Если этих файлов нет, продолжайте без предупреждений и предложений
создать их заранее. Навык domain-modeling создаёт их по мере согласования
терминов и решений.

Используйте термины словаря в задачах, предложениях и названиях тестов.
Если термина нет, проверьте, нужен ли он, и отметьте пробел для domain-modeling.

Явно указывайте противоречия существующим ADR; не переопределяйте
зафиксированные решения молча.
