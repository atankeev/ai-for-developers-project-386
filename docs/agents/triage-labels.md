# Triage labels

| Роль            | Метка           | Значение                           |
| --------------- | --------------- | ---------------------------------- |
| needs-triage    | needs-triage    | Требуется оценка задачи            |
| needs-info      | needs-info      | Нужны дополнительные сведения      |
| ready-for-agent | ready-for-agent | Задача описана и готова для агента |
| ready-for-human | ready-for-human | Требуется реализация человеком     |
| wontfix         | wontfix         | Задача не будет выполняться        |

Когда навык указывает роль, используйте соответствующую метку.
