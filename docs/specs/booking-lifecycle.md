# Жизненный цикл записи

Правила для [задачи №6](https://github.com/atankeev/ai-for-developers-project-386/issues/6).

[Согласованный итог обсуждения](https://github.com/atankeev/ai-for-developers-project-386/issues/6#issuecomment-6749861974).

Правила, переходы, ошибки и сценарии подтверждены пользователем. Реализация выполняется отдельным этапом.

## Создание и повторы

Выбор времени не резервирует интервал. Сервер создаёт запись, неделимо проверяя актуальные условия и занимая интервал. Пересечения запрещены между всеми типами встреч; соседние встречи допустимы. При отказе контакты и комментарий сохраняются в текущем процессе, доступность обновляется; автоматического выбора другого времени нет.

Одна попытка имеет устойчивый идентификатор и создаёт максимум одну запись, включая одновременные запросы с разными данными. Пока запись не создана, данные запроса можно менять; повтор проверяет текущую доступность. Предыдущий отказ не закрепляется навсегда: если интервал освободился, повтор может создать запись.

После создания идентификатор закреплён за записью. Повтор с теми же данными возвращает её с текущим статусом и ссылкой на подтверждение, даже после отмены. Изменённые данные с тем же идентификатором отклоняются. Для новой записи после успешного создания нужна новая попытка. Email служит контактными данными; несколько записей на него допустимы.

## Переходы

| Исходное состояние | Действие | Результат | Занятость |
| --- | --- | --- | --- |
| Записи нет | Выбор времени | Записи нет | Без изменений |
| Записи нет | Подтверждение, условия выполнены | Подтверждена | Интервал занят |
| Записи нет | Подтверждение, условия не выполнены | Отказ, записи нет | Без изменений |
| Подтверждена | Повтор создания с теми же данными | Та же запись с текущим статусом | Без изменений |
| Подтверждена | Отмена владельцем строго до начала | Отменена | Интервал сразу свободен |
| Подтверждена | Отмена в момент начала или позже | Отказ | Без изменений |
| Отменена | Повторная отмена | Успех, остаётся отменена | Без изменений |
| Отменена | Повтор исходного создания | Та же отменённая запись | Не занимается заново |
| Любая сохранённая запись | Запланированный конец + 30 дней | Запись и связанные данные удаляются | Без изменений |

Состояния — «подтверждена» и «отменена». «Предстоящая», «идёт», «прошедшая» определяются по времени. Для встречи в 15:00 отмена допустима в 14:59 и запрещена ровно в 15:00. Повтор отмены ранее отменённой записи остаётся успешным и после времени начала, пока запись хранится.

Конкурирующие действия должны давать результат, соответствующий последовательному порядку: запрос создания до отмены занятой записи может получить отказ; после отмены — создать запись при соблюдении остальных ограничений. Освобождение времени не отменяет минимум 24 часа до начала.

## Действующие правила №4 и №5

При создании актуально проверяются расписание и исключения, занятость, доступность и условия типа, окно бронирования и минимум 24 часа до начала. Окно — 14 календарных дней с завтра по Москве; шаг — 15 минут от начала рабочего интервала. Интервалы полуоткрытые [начало, конец).

Изменение расписания сохраняет созданные записи. Запись сохраняет исходные название, описание, длительность и интервал. Если до подтверждения изменились название/описание типа, показать новые условия и потребовать повторного подтверждения; если длительность — дополнительно нового выбора времени. Если тип скрыт, запись не создавать и вернуть гостя в каталог с сохранением контактов в текущем процессе.

## Доступ и хранение

Секретная ссылка разрешает только просмотр названия встречи, даты, времени, часового пояса и текущего статуса. Её можно открыть с другого устройства. Имя, email и комментарий на гостевой странице не показываются; полные данные доступны владельцу. Писем и восстановления ссылки по email нет. Самостоятельная отмена и перенос гостем вне объёма.

Запись, данные гостя и информация для обработки повторов хранятся 30 дней после запланированного окончания встречи, включая отменённые записи. Затем удаляются, в том числе из истории владельца. Отмена не меняет срок хранения. Неверная или истёкшая ссылка показывает «Запись не найдена» без данных гостя. Гарантии возврата существующей записи при повторе ограничены сроком её хранения.

## Ошибки

Это названия поведения, а не фиксированные API-коды.

| Причина | Реакция |
| --- | --- |
| Пересечение | «Время уже занято»; сохранить данные, обновить варианты |
| Расписание, окно или минимум 24 часа больше не допускают время | «Время больше недоступно»; сохранить данные, обновить варианты |
| Название/описание типа изменились | Новые условия и повторное подтверждение |
| Длительность изменилась | Новые условия и повторный выбор времени |
| Тип скрыт | Отказ и возврат в каталог с сохранением контактов в текущем процессе |
| Изменённые данные попытки, уже создавшей запись | Несовместимый повтор; другая запись не создаётся |
| Отмена подтверждённой записи с момента начала | «Отмена недоступна: встреча уже началась» |
| Неверная или истёкшая секретная ссылка | «Запись не найдена» |

## Проверяемые сценарии

1. Два гостя выбрали одно время: резервов нет.
2. Одновременно подтверждаются 10:00–11:00 и 10:30–11:00 разных типов: создаётся одна запись, второй запрос получает отказ с сохранением данных.
3. Соседние 10:00–10:30 и 10:30–11:00 могут быть созданы обе.
4. Двойное нажатие или потеря ответа после создания: повтор возвращает ту же запись, дубля нет.
5. После отмены владельцем повтор создания возвращает отменённую запись и не занимает интервал.
6. До создания изменены email или время с прежним идентификатором: новые данные допустимы и проверяются актуально.
7. После создания изменены данные с прежним идентификатором: отказ, новой записи нет.
8. Одновременные разные запросы с одним идентификатором создают максимум одну запись; второй не меняет её.
9. Отказ из-за занятости потерялся, интервал освободился: повтор может успешно создать запись.
10. Две независимые записи на один email в свободные интервалы разрешены.
11. Расписание изменилось до создания: проверяются новые условия. После создания: запись сохраняется.
12. До начала ровно 24 часа: ограничение выполнено; меньше — отказ.
13. Изменение названия/описания требует повторного подтверждения; изменение длительности — ещё и нового выбора времени; скрытие типа запрещает создание.
14. Отмена до начала освобождает время; повторная отмена успешна. Ровно в момент начала и позже отмена подтверждённой записи запрещена.
15. Отмена и новая запись конкурируют: результат соответствует порядку действий и не создаёт пересечений; правило 24 часов сохраняется.
16. Ссылка с другого устройства показывает условия и актуальный статус, включая отмену, без имени, email и комментария.
17. До запланированного конца + 30 дней запись доступна. При истечении срока ссылка перестаёт работать, запись исчезает из истории владельца, связанные данные удаляются.
18. Отмена не отсчитывает новые 30 дней: срок остаётся привязан к запланированному окончанию.
