# Редактирование и скрытие типов встреч

Правила для [задачи №5](https://github.com/atankeev/ai-for-developers-project-386/issues/5).

## Согласованные правила

- Название обязательно: от 1 до 100 символов после удаления пробелов по краям. Описание необязательно: обычный текст до 2000 символов. Длительность — целое число от 1 до 1440 минут; кратность 15 минутам не требуется.
- Название типа уникально среди всех типов, включая скрытые. При сравнении игнорируются регистр и пробелы по краям.
- Если длительность не помещается ни в один рабочий интервал текущего расписания, сохранение типа разрешено с предупреждением: «Длительность встречи превышает любой рабочий интервал. При текущем расписании запись невозможна». Тип остаётся в каталоге, если не скрыт; доступных слотов для него нет.
- Существующая запись сохраняет исходные название, описание, длительность и занятый интервал после редактирования типа. Изменения типа действуют только на новые записи.
- Скрытие убирает тип из каталога и запрещает новые записи, включая запись по прямой ссылке. Существующие записи сохраняются и продолжают занимать своё время.
- Скрытый тип можно редактировать и вернуть в каталог. Возвращается тот же тип с актуальными параметрами; прежняя ссылка снова работает.
- Если до подтверждения записи изменились название, описание или длительность типа, запись автоматически не создаётся: гостю показываются актуальные условия и требуется повторное подтверждение. При изменении длительности слоты пересчитываются и гость заново выбирает время.
- Если тип скрыли, пока гость заполнял форму, создание записи запрещено. Гостю объясняется недоступность типа и предлагается вернуться в каталог. Введённые контактные данные сохраняются на время текущего процесса записи; другой тип гость выбирает самостоятельно.

## Сценарии

| Действие владельца | Результат |
| --- | --- |
| Скрыть тип, пока гость заполняет форму | Запись не создаётся; гость получает объяснение и может выбрать другой тип в каталоге без повторного ввода контактов в текущем процессе записи |
| Изменить название или описание типа, пока гость заполняет форму | При подтверждении показываются актуальные условия; для создания записи требуется повторное подтверждение гостя |
| Изменить длительность типа, пока гость заполняет форму | Слоты пересчитываются; гость заново выбирает время и подтверждает актуальные условия |
| Сохранить тип длительностью 120 минут, когда все рабочие интервалы не длиннее 60 минут | Тип сохраняется с предупреждением; доступных слотов нет |
| Создать тип « консультация », когда уже существует другой тип «Консультация», в том числе скрытый | Сохранение отклоняется из-за совпадения названий |
| Переименовать тип и изменить длительность с 30 на 60 минут после записи гостя на 10:00–10:30 | Запись сохраняет прежние название, описание и длительность; занято только 10:00–10:30 |
| Скрыть тип, на который уже есть записи | Тип исчезает из каталога; новые записи запрещены и по прямой ссылке; существующие встречи остаются в силе |
| Отредактировать скрытый тип и вернуть его в каталог | Тип доступен с актуальными параметрами по прежней ссылке; условия прежних записей сохраняются |
